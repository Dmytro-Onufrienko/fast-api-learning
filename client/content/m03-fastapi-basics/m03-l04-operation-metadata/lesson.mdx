In Nest, the API contract and its documentation are two separate systems. The framework knows the route; `@nestjs/swagger` knows what the route *means*, and only because you told it a second time with `@ApiTags`, `@ApiOperation`, and `@ApiResponse`. They drift apart the moment someone changes a handler and forgets the decorator above it.

FastAPI has one source. The decorator that registers the route is the same decorator that documents it.

## The arguments worth knowing

- **`status_code`** — the success status. Defaults to `200`, but a `POST` that creates something should say `201`. Use the `status` module (`status.HTTP_201_CREATED`) if you prefer names over numbers; both are identical to FastAPI, and the numeric form is common in real codebases.
- **`tags`** — groups operations in `/docs` and, more importantly, decides how client generators name their service classes. A list, because one operation can belong to several groups.
- **`summary`** — the one-line label. Defaults to a prettified function name, which is rarely what you want in a public API.
- **description** — taken from the **docstring** automatically. Markdown is rendered. You can override it with an explicit `description=` argument, but letting the docstring do it keeps the explanation next to the code.
- **`deprecated=True`** — marks the operation struck through in the docs while keeping it fully functional.
- **`operation_id`** — the stable identifier used by code generators.

<Gotcha title="operation_id is the name your TS client will have">

Tools like `openapi-typescript`, `orval`, and `openapi-generator` derive function names from `operationId`. FastAPI's default is built from the function name, the path, and the method, which produces things like:

```
read_product_products__product_id__get
```

Your generated client then exposes `readProductProductsProductIdGet()`. Set it explicitly on anything a client will consume:

```python
@router.get("/products/{product_id}", operation_id="getProduct")
```

This is the highest-leverage five seconds in the whole file if a frontend consumes your API — and it is invisible until someone runs the generator.

</Gotcha>

## Why this matters more here than in Nest

Because the schema is derived rather than declared, it is always true. If you change a parameter's type, the docs change in the same commit — there is no second place to update and no way for them to disagree. That is the actual argument for FastAPI over Express-with-Swagger-comments, and it only pays off if you fill in the metadata.
